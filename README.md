# 青葱岁月 · 网页音游引擎

一个不依赖任何框架、不依赖构建工具的单文件 Web 音游（4 轨下落式）。
最终产物是一个 `index.html`：内嵌音轨、谱面、矢量角色，双击即玩，可离线运行，也可直接压缩上传到 B 站 Toy。

> 本仓库开源的是**游戏引擎与构建流程**。示例曲目为第三方音乐作品，音轨与由其派生的谱面数据不入库，见「版权与授权」。
>
> 仓库地址：<https://github.com/604665656/qingcong-rhythm>

## 特性

**玩法**
- 4 轨下落式，`D F J K` / 方向键 / 触屏 / 手柄四种输入
- 判定窗口 PERFECT ±85ms · GREAT ±140ms · GOOD ±200ms · MISS ±280ms
  （休闲向，比手机音游 Phigros 的 PERFECT ±80ms 还松；参考 osu!mania / StepMania / DDR / 太鼓次郎
  多款开源音游后取的手感下界，触屏手指误差远大于键盘，判定偏多半是设备/音频延迟未补偿——
  可在设置里调「判定偏移」）
- **跨轨宽容 100ms**：本轨没够到音符时，相邻轨可在 100ms 窗口内接手，点偏一格不算空按
- **长按有完整判定**：按住期间每 0.22s 持续得分，按满出 `HOLD` 收尾判定 +150，
  中途松开只丢收尾奖励并提示「断」，不判 MISS、不断连
- **连线滑条**：相邻轨快速连打的音符自动组成一条链，用光带连起来并带方向箭头，
  按住横向滑过去即可（阈值：间隔 ≤0.45s、跨 1~2 格、链长 ≥3；HARD 68 条覆盖 261 个音符；
  已修复：链尾音符不再画指向空白的箭头）
- **太鼓模式**：红=咚 / 蓝=咔 的横向玩法，谱面由四轨谱自动派生（低音轨→咚、高音轨→咔），
  命中即敲合成鼓声，与节奏天然契合；判定窗口 良 ±85ms / 可 ±150ms / 不可 ±220ms
- **判定音效**：WebAudio 振荡器合成、先用自相关估计歌曲基频并吸附到调内五声音阶，
  判定音落在歌曲音阶里天然不违和；PERFECT 高八度、GREAT 纯五度、GOOD 根音，MISS 不出声；
  音量压在音乐之下，可在设置里调判定音音量或关闭
- **个性化**：4 套主题配色（青葱 / 樱粉 / 暮蓝 / 猫橙）瞬间换肤 + 自定义昵称，存本地
- **多歌曲框架**：标题页可直接选曲，示例曲《嘶恍而过的青葱岁月》@汽水音乐（署名：许许许许许丶若辰）
- 50 连击进入 FEVER ×1.5，三难度、准确率评级、本机最佳分
- **模式切换即弹玩法**：点模式按钮切到「下落 / 太鼓」时立刻弹出该模式的玩法说明；
  首次进入某个模式也会自动暂停并提示一次（记录在本地，不会重复打扰）
- **歌词动态演绎**：歌词按歌曲进度逐字卡拉 OK 填色（已唱高亮 + 未唱压暗），
  歌词活跃时哈士喵会张嘴「开口唱」（嘴巴开合动画 + 眨眼）
- **我的 B 站身份**（合规版）：点「获取 B 站昵称和头像」从 SDK `getUserProfile` 取本人昵称与头像；
  未连接 B 站时用系统预置随机昵称。**没有自由昵称输入框**（Toy 规范不允许用户自建昵称/头像）
- **弹幕**：预置 10 条短语点选，选中后会在游戏画面上方从右往左飘过（暂停时冻结）。
  **没有自由输入框**（Toy 规范禁止 UGC 自由文本）
- **粉丝向交互**（装扮页「粉丝中心」）：粉丝牌（部分需成就解锁）、
  成就系统（初遇 / 全连 / Fever / 太鼓 / 完美 / 百连）、UP 主卡片，
  以及「去主页关注 ↗」跳转按钮（指向 UP 主主页 <https://space.bilibili.com/298813>）；结算页会展示当前粉丝牌与本局解锁的新成就
  （查询「是否已关注」需 B 站 OAuth 授权，本地版读不到，故只提供跳转关注入口，不做伪造的"已关注"提示）
- **强制横屏 / 竖屏**：标题页按钮循环 自动 → 横屏 → 竖屏，CSS 旋转整个 app，
  只在「当前视口方向 ≠ 目标方向」时旋转；选择会持久化
- **保存 / 退出**：装扮页与设置页都有独立的保存（落盘）与退出（还原快照）按钮；
  面板支持右上角 ✕、点背景、Esc 三种关闭方式。
  顺带修了判定偏移 / 速度 / 音量此前只存内存、重启即丢的问题

**谱面由音频分析离线生成，不套固定 BPM 网格**
1. ffmpeg 解码 → 22050Hz 单声道
2. STFT（frame 1024 / hop 256）+ 28 段对数频带 → 谱通量起始点检测
3. 每 2 秒窗口按能量分配音符配额，保证全曲密度均衡
4. 按频带亮度映射到 4 条轨道，做均衡与连打限制
5. 强音处且后方有空档 → 生成长条
6. 视觉重音脉冲同样取自音频重音点，而非固定节拍

自由节拍的流行曲实测节拍网格对齐率 < 25%，所以谱面跟着真实音头走。

**移动端 / 多端适配**
- 竖屏与横屏各自排版，旋转后多次重算视口（iOS 的 `orientationchange` 尺寸是延迟更新的）
- 触屏按住后横向滑动可连续触发相邻轨道（滑动连打）
- 多指互不干扰：每个 `pointerId` 独立记轨
- 用事件 `timeStamp` 换算歌曲时间并扣除触屏采样延迟，判定更"准手"
- 每次按下都有独立于判定的光环反馈，Miss 也能立刻看到手指生效
- 手柄：`A B X Y` / 十字键 / 左摇杆映射 4 轨，`Start` 暂停，`Back` 暂停，连接后左下角显示设备名

**平台层（B 站 Toy SDK）**
- 排行榜：`submitScore` / `getRankList` / `getMyRank`，**按模式分榜** × 总/月/周/日榜
  - 节奏=1 / 太鼓=2 / 九宫格=3（预留）/ 连线=4（预留）/ 5 备用
  - 平台**最多只给 5 个榜**（见下方「Toy 合规要点」），音乐 × 模式 × 难度三者无法同时分，
    因此这里选择按模式分榜，**难度最佳分只记本机**（`qc_rhythm_v1_<mode>_<diff>`，旧档自动迁移）
- 结算上报会带上 `mode` 与 `song`，平台层据此选榜
- 云存档：`getCloudStorage` / `setCloudStorage`，本地 localStorage 与云端合并取更有利值
- 体力：上限 5 点、每 1 分钟恢复 1 点、每日 20 局上限、离线恢复按时间戳补算
- 分享得体力：分享后必须真实回到页面且 ≥5 秒，云端时间戳去重 + 每日 3 次上限 + 15 秒间隔
- 成绩校验：判定总数、准确率区间、分数理论上限、时长与 Miss 比例，不通过则不入库不上榜
- 所有 SDK 调用强制超时降级，非宿主环境下自动切换单机模式，绝不卡在加载页

**Toy 合规要点（踩过的坑，改动前务必看）**

来源：《Toy 开发者 FAQ》（2026.10.23）。以下几条直接约束了本项目的实现：

| 约束 | 本项目做法 |
|---|---|
| **不允许用户自建昵称 / 头像**，只能用 SDK 用户信息或系统预置 | 已移除自由昵称输入框；昵称走 SDK `getUserProfile`，取不到时用 10 个预置随机昵称 |
| **禁止 UGC 自由文本输入**（聊天室、自由留言等属安全红线） | 弹幕改为 10 条预置短语点选，**没有任何自由输入框** |
| **不建议 b23 短链**（约一年后失效会导致 Toy 打不开） | 关注跳转用 `space.bilibili.com` 站内主页，产物中已无 b23 链接 |
| **入口 `index.html` ≤ 1MB** | 分包版 ~200KB，音轨与谱面拆成独立文件 |
| **文件包 ≤ 50MB，zip 根目录必须含 index.html** | 上架包 ~3MB，根目录直接放 `index.html` + `song.mp3` |
| **排行榜最多 5 个** | 按模式分榜（4 个 + 1 备用），难度不占榜 |
| **不得跳转站外、不得放广告、不得第三方登录** | 只保留 B 站站内跳转 |
| **必须保留免交互即可见的内容** | 游戏本体无需关注/点赞即可完整游玩 |
| **本地存储易丢失，重要数据用云存档** | 最佳分同时写本机与云存档 |
| **`api.bilibili.com` 未开放 CORS** | 浏览器直连取不到用户信息/头像 → UP 主头像随包内置（data URI ~3KB），联网再尝试刷新 |

**横竖屏（已接官方能力）**
- 优先 `sdk.setContainerMode({ orientation })`，取值 `portrait` / `landscape` / `auto`
- 容器接管后**不再叠加 CSS 旋转**（否则会转两次）；容器不支持时（web / 旧版 App，
  SDK web 实现会抛 `unsupported`）回退到 CSS 旋转 `#app`
- 监听 `sdk.onContainerChange`，安全区写入 `--safe-top/right/bottom/left` CSS 变量
- `sdk.getContainerState()` 返回 `{deviceType, viewport, orientation, immersive, safeArea, changedFields}`
- `sdk.getUserProfile()` 返回 `{avatar, nickname, toyOpenId}`

**备注**：SDK 另有 `checkInputSafety({text, scene})` 可做文本内容安全校验。
若将来想放开弹幕自由输入，需先接这个接口——但 FAQ 四、10 仍写着「绝对禁止提供 UGC 能力」，
且四、5 说明即便接入也「仍需以平台审核结论为准」，所以当前**默认保持预置短语点选**以求稳过审。

**其它**
- 老板键：`Alt + X` / `` ` ``，手机上三指长按 500ms；伪装成 Excel 工作排期表

## 快速开始

```bash
# 1) 准备音轨与歌词
#    song.m4a / song.lrc 放在任意位置

# 2) 分析音频、生成谱面（需要 numpy，ffmpeg 可用 FFMPEG_EXE 指定）
python build/analyze.py 你的音频.m4a 你的歌词.lrc build

# 3) 注入模板，产出两份
python build/build.py
# → index.html        单文件版 ~3.9MB，音轨内嵌，双击即玩 / 适合 itch.io
# → dist/             分包版 index.html ~169KB + song.mp3 2.8MB，适合 B站 Toy
```

为什么要有两份：B 站 Toy 限制 **`index.html` 解压后 ≤ 1MB**，内嵌 base64 音轨会直接超限被拒（提示「请将内联的脚本、样式或图片拆成独立文件」）。分包版把音轨改成相对路径 `song.mp3`，正文只有 142KB。

`build.py` 会替换模板里的 `__SONG_DATA__` / `__AUDIO__` / `__PLATFORM_CSS__` / `__PLATFORM_JS__` 占位符，并断言四个都被替换干净。`__AUDIO__` 既可以是 `data:audio/mpeg;base64,...`，也可以是 `song.mp3` 这样的相对路径，前端两种都支持。

### 在手机上测

`file://` 打开时 iOS 可能禁止读取内嵌音频。用同网段的 http 服务最稳：

```bash
python -m http.server 8080
# 手机访问 http://<电脑内网IP>:8080/index.html
```

即使音频真的读不出来，页面也会给出「重试 / 静音试玩」两个按钮，不会一直卡在加载页。

## 打包上架 B 站 Toy

Toy 有两条硬限制，直接决定了产物形态：

- **`index.html` 解压后 ≤ 1MB** → 音轨不能内嵌（内嵌版 3.9MB），必须用 `dist/` 分包版
- **不允许内联脚本/样式/图片** → 但本项目脚本本来就在 `<script>` 里，真正超标的是 base64 音轨；拆出 `song.mp3` 后 index.html 仅 169KB，两条限制同时满足

```bash
python build/build.py      # 产出 dist/index.html + dist/song.mp3
# 把这两个文件放在同一层压成 zip，直接投 https://www.bilibili.com/toy/publish/
```

平台层会自动检测宿主：`window.toy` 存在 → 云端模式（排行榜/云存档/分享）；否则 → 单机模式，功能自动降级为本地存档。

## 两个已知的坑

**1. 本机代理会让本地自测连不上 127.0.0.1**

如果环境里设了 `HTTP_PROXY`，无头浏览器和 curl 会把 localhost 也走代理，结果是页面空白、`base` 探测全 false。自测时加 `NO_PROXY`：

```bash
NO_PROXY=1 PAGE_URL=https://… node build/qa2.js     # 或 http://127.0.0.1:8080/index.html
curl --noproxy '*' http://127.0.0.1:8080/index.html
```

**2. 带 `?sharecode=` 的分享链接会把静态资源也挡在参数后面**

`fetch("song.mp3")` 按相对路径解析时会丢掉查询串 → 音轨 403。`shareAwareUrl()` 会把当前页面的 `sharecode` 显式补回去；没有该参数的环境（Toy / itch.io / 本地）完全不受影响。分享时也别忘了带上 `?sharecode=`，只发域名会看到 403「链接不完整」。
